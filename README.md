One image summing up the world's news of Thursday 19 November 2026: the first-ever Trump–Xi–Putin trilateral summit in Shenzhen leads a dense front page of 36 verified stories from six continents, with a world-map panel marking 12 places that made the day. The front page is composed by compose.py (Pillow) from a fresh hero illustration, and main.ts copies the finished 1024x1024 image to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

To rebuild the image from the hero illustration, run `python3 compose.py` first (needs Pillow).
